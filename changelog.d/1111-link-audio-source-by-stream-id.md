- A camera linked to a BirdNET-Go source now stays linked when you rename the source in BirdNET-Go. **Add detected source…** and the list of detected sources under **Settings → Integrations → BirdNET-Go** save the stream's ID, which BirdNET-Go keeps across a rename, and each linked source shows its current name beside the ID (`ESP32 v3.0 X · rtsp_52d54d7d`) and when it was last heard. A camera still linked by a name its stream no longer uses says so ("ESP32 v3.0 is now called ESP32 v3.0 X.") with **Link by stream ID**, which adds the ID and keeps the old name only while calls from before BirdNET-Go sent IDs still match it; nothing changes until you save. The list shows each stream once, under its newest name, and no longer loses a quiet microphone behind busier ones. Changing a stream's address or password in BirdNET-Go gives it a new ID, so link the camera again then; sources from older BirdNET-Go versions still link by name. The list of sources is now for the owner only. See [the BirdNET-Go guide](docs/integrations/birdnet-go.md#renaming-a-source-in-birdnet-go) and [the API reference](docs/api.md) (#1111).
