## What Phase 0 asked for, and what this delivers

The design's Phase 0 freezes the contract before the schema work starts: pin the source
releases, gate provenance machine-readably, and inventory every supported model artifact
with its declared label grammar. Delivered:

- **The source manifest**: [`backend/app/assets/species_sources.json`](../../backend/app/assets/species_sources.json),
  validated and enforced by `app/services/species_provenance.py`. Every source carries a pinned
  release, URL, licence, citation, and an explicit redistribution decision
  (`bundled` / `build-input` / `runtime-fetch` / `forbidden`). The reference builder now refuses
  a source outside the manifest, a source whose decision does not permit building, and an input
  file that is not the pinned release. Adopting a new release means updating the manifest in the
  same commit — that is the freeze working, not an obstacle.
- **The artifact inventory and mapping evidence**:
  [`docs/reviews/2026-08-19-species-catalogue-phase0-inventory.md`](../reviews/2026-08-19-species-catalogue-phase0-inventory.md),
  generated by `backend/scripts/build_species_catalogue_inventory.py` from checksum-verified
  label files. It covers 100% of supported artifact checksums, and a regression test fails CI
  if the registry changes without the inventory being regenerated.
- **Label grammar declared per artifact** in the model registry (`label_format`), replacing both
  the hardcoded scientific-file list and shape-guessing.

## The declared label grammars

Verified against the published, checksum-matched label files on 2026-08-19:

| Format | Artifacts | Shape |
| --- | --- | --- |
| `scientific_hierarchy` | `rope_vit_b14_inat21` | `04815_Animalia_…_Cyanistes_caeruleus` — the one shape a common name cannot take, so it is the only format read without a declaration |
| `scientific_binomial` | `convnext_large_inat21`, `eva02_large_inat21` | bare `Genus species` |
| `scientific_paired_common` | `mobilenet_v2_birds` | `Haemorhous cassinii (Cassin's Finch)` |
| `common_name` | `flexivit_il_all`, `eu_medium_focalnet_b`, `small_birds/eu`, `small_birds/na`, `medium_birds/eu`, `medium_birds/na` | resolves by lookup only |
| `detector_classes` | both crop detectors | not taxa; excluded from species mapping and enrichment |

### The defect this surfaced

The paired form was being read *without* a declaration, on the theory that its shape announces
itself. The NABirds files disprove that: `Lesser Goldfinch (Female/juvenile)` matches the paired
shape exactly, so the automatic taxon map recorded `Lesser Goldfinch` as a scientific name for
both North American regional artifacts. The parser now reads a shape only when the artifact
declares it, those labels resolve through the bundled reference (whose lookup already tries the
half before the parenthetical), and detector class lists are excluded outright — COCO's `kite`
must never resolve to a bird.

## Measurements recorded in the inventory

- The reconciliation's open measurement — the European labels resolving to no scientific name in
  any held source — comes to **84 of 707 (11.9%)** against the bundled IOC reference. The list
  makes the dominant cause visible: the label files strip possessive apostrophes (`Audouins gull`
  vs IOC's `Audouin's Gull`). An apostrophe-insensitive match in the Phase 2 alias layer should
  recover most of them; the remainder are naming-authority drift (`Feral pigeon`, `Great bittern`)
  and one explicit `Unknown` class for a `class_kind` declaration.
- The NA files additionally carry `(ID: 447)`-style suffixes on 30 of their unresolved labels —
  worth an alias rule of its own rather than ad hoc stripping.
- The shared iNat21 binomial file parses 9,999 of 10,000 labels as binomials; the exceptions and
  the 8,514 non-bird classes await the pinned Catalogue of Life import.

## What Phase 0 still owes

The design also asks for a report of **exact, synonym, split/lump, aggregate, hybrid, and
unresolved** mappings against the canonical taxonomy. The synonym and split/lump analysis needs
the pinned COL26.7 export and the eBird crosswalk actually loaded, which is the first act of
Phase 1's importer; producing it before that machinery exists would mean a throwaway pipeline.
The unresolved and non-species portions are already recorded in the inventory. The roadmap keeps
Phase 0 marked in progress until that report exists.
