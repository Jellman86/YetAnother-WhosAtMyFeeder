Five fixes, no new features. The one most likely to matter to you is the first: if filtering the
Explorer by a species has been coming back empty, this release is why it will stop.

## Smoother everyday use

- **Filtering by a species finds your visits again.** 2.19.0 made a species filter answer by index
  lookup, and that lookup only checked the taxon id stored on the detection itself. Where those ids
  are patchy the filter reported "no visits match these filters" for a species with plenty of
  visits, and adding a date range appeared to fix it because that routes the query down the older
  path. Both paths now agree, and a page can no longer show a visit that the total did not count.
- **A busy feeder stops making the whole interface wait.** Loading a page of visits asks Frigate
  about every event on it, and it did that while holding one of the five database connections the
  app shares. On a real install that hold reached 27 seconds, and everything else queued behind it.
  Measured on the reference install after the change: 18 milliseconds. Resetting a database
  appeared to help before only because a smaller history asks about fewer events.
- **A bird keeps its identity, or honestly loses it, but is never filed as the wrong one.** A later
  result for the same species could erase the identity a startup pass had resolved, which is how
  one bird came to be counted as two. A correction now records the corrected species rather than
  leaving the previous one in place.
- **Choosing a photograph talks about the picture.** The frame picker offered "Frigate hint crop"
  and "Model crop", which describe which part of the app made a frame. It now says whether a frame
  is the whole frame, close on the bird, or as Frigate recorded it.

## Before you update

- **No special steps.** No schema changes and no settings to revisit.

## Good to know

- If you configured Home Assistant weather before 2.19.1 and it came back blank, that was fixed in
  2.19.1, but an access token erased by the earlier fault cannot be recovered and needs entering
  once more under Settings, Integrations.
- The species filter fault and the interface slowdown were both found by people running this at
  their own feeders and measuring carefully. That is worth more than any guess made here.
