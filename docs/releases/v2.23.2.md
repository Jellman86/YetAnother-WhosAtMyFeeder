YA-WAMF 2.23.2 fixes the Species page for anyone whose language gives two birds the same name. If your
Species page stopped loading after a recent update, this is the fix.

## What's fixed

- **The Species page loads when two birds share a translated name.** In German, for example, both the
  Eurasian Nuthatch (*Sitta europaea*) and the nuthatch family (Sittidae) are called "Kleiber". The page
  could fail to load when both were among your top species. Where two names match, the charts, the
  activity picker and the photo wall's share bar now add the scientific name, such as
  "Kleiber (Sittidae)", so you can tell them apart.
- **The activity picker shows the bird you picked.** It used to ask for a bird by its translated name,
  which cannot tell two such birds apart. It now asks by scientific name.

## Before you update

- **No special steps.** Back up `/config` and `/data` as usual, then wait for the container health check to
  pass. This update has no database migration and needs no setting changes.
- **You can undo any workaround.** If you renamed a bird so the Species page would load, you can change the
  name back. Your detections were never affected.
- Unsuffixed image tags remain the full compatibility image. See the
  [provider-family guidance](https://github.com/Jellman86/YetAnother-WhosAtMyFeeder/blob/v2.23.2/docs/setup/hardware-acceleration.md)
  before choosing an optional CPU, Intel or CUDA image.

## Good to know

- **Updated web framework.** The backend now runs FastAPI 0.162.0, and the minimum Pillow version is 13.0.0.
  The API is unchanged.
- **How this was checked.** The fix was tested in a browser with two birds sharing a German name. This release
  also ran on an Intel install with live detections, and its Species page was checked in German.
